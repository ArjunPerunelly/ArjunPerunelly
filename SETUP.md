# Install the ArjunPerunelly GitHub profile style

## Profile repository
The repository must be named exactly `ArjunPerunelly` and be public for its README to appear on your profile.

If your account username is still `ArjunAchu404`, change it in GitHub Settings → Account first (only if `ArjunPerunelly` is available). Then rename/create the special profile repository to match the new username.

## Upload these files to the repository root
- `README.md`
- `profile-banner.png`
- `neko-project.svg`

Commit the files, then open https://github.com/ArjunPerunelly.

## To match the screenshot's sidebar
In GitHub, use **Edit profile** to set your display name, bio, avatar, and any links you want to share. Upload the monochrome anime image as your avatar. Pin your best repositories on your profile.

The sidebar, contribution graph, status panel, and profile navigation are GitHub-native UI and cannot be recreated or repositioned by the README itself.
